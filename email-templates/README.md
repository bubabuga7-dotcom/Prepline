# Shyn — шаблоны писем Supabase

Supabase → Authentication → Emails (Templates). Для каждого письма: Subject = строка ниже, Body = содержимое файла.

- `1-confirm-signup.html` — Subject: **Confirm your email — Shyn**
- `2-reset-password.html` — Subject: **Reset your password — Shyn**
- `3-magic-link.html` — Subject: **Your sign-in link — Shyn**
- `4-change-email.html` — Subject: **Confirm your new email address — Shyn**
